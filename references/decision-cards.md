# 决策预检卡（三行卡）规则

任何买入/加仓/卖出决策前 30 秒填卡，数据存 portfolio.db（decision_cards 表），不许手工记 md。**先填卡，后下单**；收盘只做验证，不补卡（已成交才补卡=事后解释，记违规；除非当日主动向用户报告补录）。

## 三行定位

- **① 触发**：买点条件，尽量写死（收盘可查）
- **② 验证点**：方向性判断即可（如"不破止损即逻辑成立"），**不要求预测价格**——预期不会准，作用是事前留痕、事后对照
- **③ 证伪/止损**：硬约束，必须精确，这是唯一"很清楚"的位置
- 全模糊 = 还没想清楚，先别下单

## 铁律（教训沉淀）

- **卡必须来自用户主动决策**：止损位/条件单是纪律执行，用 condition_orders 和 rule_triggers 管理，禁止把风控线自动转成"卖出"决策卡；Codex 无权替用户预设买卖方向
- **触发条件引用均线写动态表述**（如"收盘站上当日 MA20"），禁止写死历史数值；plan_price 仅参考，以触发时当日均线判定
- **预期不预测价格**：所有卡的验证点必须是方向性表述，不带价格目标

## 命令

- 填卡：`python card.py add --account real|sim --code <代码> --name <名称> --dir 买入/加仓/卖出 --qty N --price X --trigger "如果A" --expect "那么B" --invalidate "何时认错"`
- 执行：`python card.py exec <id>`
- 验证：`python card.py verify <id> --result 命中/未命中 --note "实际走势"`（漏验=违规）
- 撤卡：`python card.py delete <id>`
- 查看/统计：`python card.py list` / `python card.py stat`

## 成交价规则（防后视镜）

**成交价必须是"触发确认时刻"的实时价**，禁止用当天收盘价成交当天确认的触发。

- 盘中触发 → 触发时刻实时价成交
- 收盘确认类触发 → 次日开盘/盘中实时价成交，或尾盘 14:50-14:55 实时价
- 每笔标注：成交时间、价格、来源（✅实时价/✅尾盘价/✅次日开盘价/❌收盘价=违规）

## 盘中监控（对照账户）

- monitor.py：盘中每 1 小时自动检测（9:45/10:45/11:20/13:45/14:45），命中写 trigger_log.txt + 弹窗
- 命中后 Codex 按日志中的实时价成交，主动跟进，不等用户提醒
