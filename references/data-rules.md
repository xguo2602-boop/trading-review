# 数据查证规则

## 价格来源分级

- ✅ 用户实时报价 / 官方收盘价：可靠
- ⚠️ 搜索查证：需注明日期，禁止混用不同日期数据
- ❌ 无法确认：标"待确认"，**禁止估算冒充**

## 硬性要求

1. 实时盘中数据以用户报价为准；搜索只做新闻/财报/事件的背景补充
2. 计算涨跌幅必须标注基准日期（例：用 8/11 收盘算 8/13 涨跌幅=错误）
3. 对照账户每个成交价标注来源，无法确认的标"待确认"并下一日补录
4. 违反此规则的数据，月底对比时该笔作废
5. 技术指标以脚本计算为准（portfolio_updater.py：MA/RSI/MACD），不手动估算

## 已知教训（别重犯）

- A 股最小交易单位 100 股，不存在"卖 50 股"
- 搜索会混入旧年份报道，使用前核对日期
- 半场数据 ≠ 全天数据；午评 ≠ 收评
