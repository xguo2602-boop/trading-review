# 每周小检 + 每月大检

## 每周小检（周五盘后）

1. 本周命中记录汇总（大V vs Codex，谁更准）＋核对命中记录表完整度
2. 条件单执行情况（挂了几张/漏几张/触发几张）
3. 市场阶段定级回顾（本周标签定对没）
4. 机会记录（本周错过什么）
5. 每日复盘完成度（5 天完成/缺几天，缺的补）

只汇总，不改规则。

## 每月大检（月底，规则修改权打开）

1. 每条规则统计"触发次数 + 触发后盈亏"；触发 <5 次不改，只标待观察
2. 体检双向提问：帮我少亏了吗 + 让我少赚了吗
3. 命中率统计定"谁更可信"；绩效表对比大盘
4. **规则修改权只在此刻打开**：平时一律不许改（防手痒→开后门）
5. 对照账户 vs 真实账户两轴对比（见 sim-account.md）
6. 讨论项参考：70% 仓位上限是否随"全进攻形态"调整（用户多次提到双V 满仓）

## 豁免规则

豁免必须"显式 + 限时"（写进 §1，到期自动恢复）。例：宝丰 -15% 红线豁免至 8/13。
