# 对照账户（纸面）维护

目的：检验"无规则临场抉择" vs "规则体系"哪个更正确。纯纸面，不动真钱。月底两轴评分对比。

## 每日动作

1. **检查待执行清单**：看触发条件是否满足（紫金企稳买 100、512100 回踩 MA5 加仓、黄金回调加仓等）
2. **触发即执行**：记录成交价、来源、时间
3. **已实现盈亏**：卖出时记录（如 562800 -124.8、159792 -62）
4. **更新日报**：portfolio_updater.py 已覆盖真实+对照两个账户

## 成交价规则（8/19 确立，防后视镜）

**核心：成交价必须是"触发确认时刻"的实时价，禁止用当天收盘价成交当天确认的触发（=看完全天走势再买，不公平）。**

1. **盘中触发**（如缩量止跌、站上均线）：用**触发确认时刻的实时价**成交，记录时间+价格来源
2. **收盘确认类触发**（如"收盘站上 MA20"）：确认点在收盘后 → 成交**顺延到次日开盘/盘中**，用次日实时价成交（模拟"看到信号后第二天操作"）；或当天**尾盘 14:50-14:55 用盘中实时价**成交（模拟尾盘操作）
3. **禁止**：用当天收盘价成交当天确认的触发
4. 每笔成交必须标注：成交时间、价格、来源（✅实时价/✅尾盘价/✅次日开盘价/❌收盘价=违规）
5. 历史瑕疵标注：8/17 紫金买入用收盘价 33.36 成交（规则确立前），标注"旧规则瑕疵"；8/18 黄金加仓 9.527 为盘中实时价（合规）

## 信号与成交的严格对应（8/19 补充）

**凡是收盘才能确认的信号（缩量、下影、收盘站上均线、收在 X 上方），成交一律用确认后的首个交易日的开盘价/盘中实时价，禁止用确认当天的收盘价。** 即：收盘看信号 → 次日执行，价格用次日不知道走势的实时价。盘中实时可见的信号（如 14:30 分时缩量横住、不再创新低）才允许当天尾盘按实时价成交。模拟时统一按"收盘确认→次日开盘价成交"执行，与上班族用户（无法全天盯盘）的真实约束一致。
